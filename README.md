# GitHub Copilot Demo

Este repositorio contiene una demostración de cómo GitHub Copilot puede explicar el funcionamiento del código.

## Carpeta incluida

- `Explain the code/ExplainTheCode.md` — versión traducida del ejemplo original.
- `expresiones regulares/RegExInstructions.md` — versión traducida al español de México del ejercicio original.

## Objetivo

Mostrar cómo Copilot interpreta y describe código fuente usando lenguaje natural, ayudando a entender mejor funciones y algoritmos sin necesidad de leer cada línea manualmente.
